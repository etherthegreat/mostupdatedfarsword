## Reading an entry

- **Fires when** — explicit trigger rows, inbound chain links, flag gates, or the code site that spawns it. An `X_INTIMATE` event is reached from `X` when the player picks *intimate* at the scene-nav prompt (`event_scene.gd:114`).
- **Choices & outcomes** — one row per button: its text, its mechanical effect, and any event it leads to.
- **Leads to** — the outbound edges, with the target's headline, so you can write a hand-off that lands.

| `FORT_004_BTN1` | `FORT_004` | Accept the Resolution | `FORT_005` |
